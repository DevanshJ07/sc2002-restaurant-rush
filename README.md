# SC2002 Restaurant Rush

Group 4 Java command-line restaurant management project. Implementation follows the team's approved Refined Class Design v3 and the assignment brief.

## Development status

Repository setup only; no runnable game has been implemented yet. Build and run instructions will be added with Stage 1.

## Coding ownership

Devansh owns the controller, CLI, application setup, arrivals and final integration. ZN owns the domain classes and staff behaviour.

See [CODING_PLAN.md](CODING_PLAN.md) for detailed responsibilities, the shared API contract, parallel development instructions, acceptance checks and copyable AI prompts. A sequential fallback is included.

## Stage releases

- `stage-1`: Regular customers, core restaurant flow, victory and defeat.
- `stage-2`: VIP and Critic behaviour.
- `stage-3`: Host, ComboMeal and Happy Hour.

Create each tag only after its version compiles, runs independently and passes its acceptance checks. Stage 1 must contain no Stage 2 or Stage 3 features.

For each transition, record new, changed and removed files, reasons for changes, and commit/compare links. Add reproducible run evidence and video timestamps as development progresses.
